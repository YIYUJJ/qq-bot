# v0.1.0

首个正式版本：一个跑在 DSH 里的 QQ 群拟人聊天机器人，直连 SnowLuma（OneBot v11）。

## 亮点

- **一轮模型调用出回复**：不经过 agent 会话，首字通常 0.8~1.5 秒。
- **有记忆**：长期事实（相似度去重 + 归档）、画像、摘要、群内关系、每日日记。
- **会看图/看视频**：图片与表情包识图、视频抽帧描述、视频链接解析、文档读取、网页摘要。
- **像真人**：情绪状态、长度浮动、拆句、去 AI 味、@ 与引用、防重复。
- **只在白名单里说话**：群/私聊白名单硬约束，默认关闭，管理员指令需二次确认。

## 本轮新增

- **持久化**：`replied` / `usage` 落到 SQLite（空库自动从 JSON 导入，失败回落 JSON）。
- **可观测性**：每条消息带 `traceId`，reply 事件记录 `decideMs / generateMs / sendMs`；面板「运行指标」卡片可看阶段耗时与最近一次回复。
- **测试**：63 套单元测试（此前 3 套）+ 19 项集成测试（此前 8 项），覆盖收消息→决策→生成→发送、表情入库、提醒、拍一拍、识图、撤回、投票、小游戏。
- **质量闸**：ESLint `no-undef` 静态检查（抓出并修复 9 处"名字没定义/没导入"的运行时隐患）、依赖注入审计、GitHub Actions CI。
- **结构**：`lib/index.js` 从 5700 行降到约 960 行，其余拆成 67 个模块；本版本又把 7 个过小的模块合并回去。

## 已知限制

- 只在 Windows 上验证过。
- docx/xlsx 依赖本机 Python；PDF 需要 `pypdf`。
- 视频链接依赖 `yt-dlp`，抽帧依赖 `ffmpeg`。
- 不支持语音条（无 ASR）。
- 没有大群并发压测；设计目标是情侣/小群场景。
